# Workspace Growth 360

This Next.js site is published to [GitHub Pages](https://rehmandigaptics.github.io/Workspace-Growth-360/).

## Deploy

Pushing to `main` runs `.github/workflows/deploy-pages.yml`. The workflow runs lint and tests, builds the static site, and deploys the `out` directory. Set the repository's Pages source to **GitHub Actions** in **Settings → Pages**.

## Local development

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
